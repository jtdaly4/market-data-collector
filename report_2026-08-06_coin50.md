# Report — COIN50 index collection (2026-08-06)

Requested by James/Daedalus: get the Coinbase 50 Index (COIN50) price series into
the collector, full history. Delivered in two parts — a price-history backfill
and forward funding capture — with the honest caveat that what's reachable
keyless is the **perp**, not the raw index.

## Route
Tried in the specified order:
- **(a) Coinbase International (INTX) index endpoint** — `403 ip not allowed`.
  INTX is geo-blocked from this US IP. Dead here.
- **(b) consumer price page (coinbase.com/price/coin50)** — history is served by
  Coinbase's **private GraphQL** (`graphql.coinbase.com`); reachable keyless but
  the schema is undocumented and the chart hydrates client-side, so there is no
  stable series to lift without reverse-engineering it. Fragile; not used.
- **✅ chosen: Coinbase brokerage market candles for `COIN50-PERP-INTX`** — the
  same keyless public endpoint family used for the other perps. Full hourly +
  daily history back to launch.

No route required a key, login, or paid plan → the hard-stop did not trigger.
Subscribed to nothing; created/handled no key. No third-party mirror used.

**This is the COIN50 PERPETUAL, which tracks the index within a funding-driven
basis — not the raw index level.** Labelled as the perp, source-stamped
(`labels never lie`). Getting the raw index would require INTX from a non-US IP
or reverse-engineering the consumer GraphQL — flagged, not done.

## What's stored

### 1. Price-history backfill → `index_prices.db` (collector-owned, local)
New table, does NOT touch market.db, does NOT edit the engine repo:
`index_candles(ts, index_id, granularity, open, high, low, close, volume, source)`,
`INSERT OR IGNORE`, source-stamped. Recipe: `fetch_index_candles.py` (committed).

| granularity | rows | first (UTC) | last (UTC) | complete | gaps |
|---|---|---|---|---|---|
| hourly (3600s) | 15,044 | 2024-11-12 14:00 | 2026-08-06 13:00 | 99.2% | 90 micro-gaps, 124 bars, biggest 8h |
| daily (86400s)  | 633    | 2024-11-12       | 2026-08-06       | 100%     | none |

0 duplicate rows; reaches the ~2024-11-12 launch. The `.db` is gitignored (local,
re-fetchable) like market.db; the recipe script is on GitHub.

### 2. Forward funding capture → collector's perp bucket (git-tracked)
Added `COIN50` to `universe.json` perps, so the hourly GitHub-Actions cron now
snapshots `COIN50-PERP-INTX` **funding_rate + open_interest + mark** into
`data/perp/*.csv` every run (index/basis null — no COIN50-USD spot). Verified on
a live run: `funding_rate 9e-06, open_interest 2811.96, mark 244.19`.

**Funding is the irreplaceable series** — Coinbase serves no funding history, so
this only accrues forward from 2026-08-06. Starting it now is the whole point.

## The two earlier decisions, resolved
- **Perp vs raw index:** proceeding with the perp (clean keyless tracker). Raw
  index remains available only via INTX-from-non-US-IP or the fragile GraphQL —
  say the word to pursue.
- **Forward collection wiring:** resolved by putting COIN50 in the collector's
  own perp bucket (existing cron), rather than a new daemon or an engine-repo
  edit. Funding/OI now self-collect; the price-history `.db` is a one-shot
  backfill (re-run `fetch_index_candles.py` to top it up).
